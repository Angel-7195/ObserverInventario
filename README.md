Proyecto Gestión de Inventario para Diseño de Sistemas de Información

## Sistema completo en Java Swing (Mercado La Economía)
Incluye CU01–CU11, patrón Observer, controladores, exportación a Excel/PDF,
importación CSV, contraseñas cifradas, persistencia y respaldos.

    javac -encoding UTF-8 SistemaInventarioMercadoEconomia.java
    java SistemaInventarioMercadoEconomia
